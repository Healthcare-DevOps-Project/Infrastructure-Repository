# Healthcare DevOps Project

## Project Overview
This project implements an end-to-end DevOps environment using
GitHub, Terraform, AWS, Docker, Jenkins, Maven and Amazon ECR.

## Technologies
- GitHub
- Terraform
- AWS
- Docker
- Jenkins
- Maven
- Amazon ECR

## Project Implementation
1. GitHub Organization & Repository Setup
2. Git Branching and PR Governance
3. Terraform Backend Initialization
4. AWS Networking
5. Security Groups
6. Docker Installation
7. Jenkins Deployment
8. Jenkins Credentials
9. Maven Docker ECR Pipeline
10. Project Documentation
